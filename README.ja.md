## 現在開発しているもの

> **LLMを活用したWeb自動化システム — 広島大学**
>
> ローカルLLMとブラウザ制御、DOM理解、操作実行、プランニング、メモリを連携させたモジュール型研究プロトタイプです。

```text
ユーザー目標 → プランナー → ブラウザ操作 → DOM観測 → メモリ → 次の操作
```

- **Python／Playwright**によるブラウザ自動化
- DOM解析と操作可能要素の抽出
- クリック、入力、画面遷移、送信操作の構造化
- モジュール化したプランナーとメモリ機構
- ローカルLLMによる操作計画
- 動的Webナビゲーションタスクの実験設計
