## Currently Building

> **LLM-Driven Web Automation System — Hiroshima University**
>
> A modular research prototype connecting a local LLM with browser control, DOM understanding, action execution, planning, and memory.

```text
User Goal → Planner → Browser Actions → DOM Observation → Memory → Next Action
```

- Browser automation with **Python and Playwright**
- DOM parsing and interactive-element extraction
- Structured click, input, navigation, and submission actions
- Modular planner and memory components
- Local-LLM integration for action planning
- Experiment design for dynamic web-navigation tasks
